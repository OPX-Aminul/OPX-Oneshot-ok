Installation

One sequence.
Any Linux.

# clone the laboratory
git clone https://github.com/OPX-Aminul/OPX-wifi4.git
cd OPX-wifi4
sudo bash install.sh

# the only command that matters
sudo wifi4

Debian, Ubuntu, Kali, Alpine, Arch, Fedora, openSUSE, Void. The installer detects the family. You select the interface. Then WiFi Attack or AP Mode.
